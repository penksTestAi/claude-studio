Collatz Trails

Take a whole number. If it is even, halve it. If it is odd, triple it and add one. Repeat. Every number tried so far ends at 1. Nobody has proved that all of them do; that is the Collatz conjecture, posed by Lothar Collatz in 1937. This page counts the steps for every number up to a limit you choose, and draws the path of any one of them.

The page checks each number up to the limit by running the rule, so the numbers shown are what it actually found. A check up to a limit is not a proof for all numbers. The conjecture is still open. Other people have checked far larger ranges; that figure is from memory and is not checked on this page.
