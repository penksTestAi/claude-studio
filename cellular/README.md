# 256 Little Worlds

All 256 elementary cellular automata: a ring of on/off cells where each cell's next state depends on itself and its
two neighbours. Pick a rule number or flip the eight table entries, choose one starting cell or random cells, and watch
the generations. The page runs its own checks: rule 90 gives 2^(ones in n) cells in row n, rule 30's centre column starts
1101110011, rule 184 conserves its cells.

Single static page, no dependencies. Wolfram's numbering and the history (rule 110 universality by Cook, 2004) are from memory.
