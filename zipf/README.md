# Zipf and the Monkey

An essay that counts its own words. The rank-frequency chart beside the text plots the essay itself, so the
numbers quoted in the paragraphs are computed live from the page.

- Tick **Let the monkey type** to add a random typist (George A. Miller's 1957 thought experiment) with the
  same number of words. Switch between equal keys (a visible staircase) and English letter frequencies.
- The **Heaps** chart shows vocabulary growth, where real text and the monkey part ways.
- Paste your own text or open a `.txt` file; counting happens in the browser and nothing is sent anywhere.

The essay is short, so its fitted slope is about 0.71 rather than the textbook 1. The page says so.
