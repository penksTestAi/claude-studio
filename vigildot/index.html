Widths: expected from the file, measured in this browser

Expected width is the sum of the advance widths the page reads out of the font file (hmtx table), scaled to the size. Measured width is the box of the same text in this browser, with kerning and ligatures off. The last row is a control: the same text in a fallback serif should not match, which shows the test can fail.

What is not checked, and the licence

Not tested in other apps or for print. I only checked it in the headless Chromium browser that runs this page. I did not install it in a word processor, a design tool, an operating system or a printer, and I did not look at it printed. Lowercase letters use the same shapes as capitals. There is no kerning, no accented letters, and no hinting. The shapes are my own design on a 5 by 7 grid; I have not compared them with other pixel fonts for look-alikes.
